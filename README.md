Temperature Converter

A simple Java Swing desktop application that converts temperatures between Celsius, Fahrenheit, and Kelvin.

Features
Convert between Celsius (C), Fahrenheit (F), and Kelvin (K) in any direction
Simple graphical interface built with Java Swing
Press Enter in the text box or click Convert to calculate
Clear button resets the input, result, and unit selections
Input validation with friendly messages for empty or non-numeric input
Results rounded to two decimal places
